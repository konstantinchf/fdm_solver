# fdm_solver
# FDM Schrödinger–Poisson–Gross–Pitaevskii Solver

GPU-accelerated solver for fuzzy dark matter simulations. Includes mass-scan, granular noise analysis, and norm conservation tests.

## Requirements
- Python 3.10+
- PyTorch with CUDA
- NumPy, SciPy, Matplotlib, Pandas

## Installation
```bash
pip install -r requirements.txt
